# DigiPermit Frontend

Ionic Angular mobile-first UI for DigiPermit.

## Setup

1. Ensure backend is running at `http://localhost:3000`
2. Update `src/environments/environment.ts` if needed
3. Install and run:

```bash
npm install
npm start
```

App runs at `http://localhost:8100`
